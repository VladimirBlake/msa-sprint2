# Отчет по выполнению задания 3
В рамках задания был создан query resolver для запроса bookingsByUser (который стучится в сервис бронирований по gRPC).

Для получения информации об отеле в запросе бронирований по пользователю был создан пул подключения к базе данных hotelio, который был использован в создании DataLoader (обертка загрузчика данных об отелях, которая позволяет решить N+1 проблему)

Подграфы были объединены в единый суперграф, который пробрасывает в контекст HHTP header с userid для авторизации запросов о бронированиях.
